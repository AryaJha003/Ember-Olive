# 🍽️ Ember & Olive

A modern, responsive restaurant website designed with a premium and elegant visual style.

## 🌐 Live Demo

https://aryajha003.github.io/Ember-Olive/

## ✨ Features

- Responsive design for desktop and mobile
- Mobile navigation menu
- Interactive reservation form
- Restaurant menu section
- Experience and gallery sections
- Smooth navigation between sections
- Modern typography and visual design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, including desktop, tablet, and mobile devices.

## 📌 Project Purpose

This project was created as a practical web-development project to explore responsive design, user interaction, and modern website presentation.
